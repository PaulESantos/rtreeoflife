# Plot FASTA summary with ggplot2

Plot FASTA summary with ggplot2

## Usage

``` r
tol_plot_fasta_summary(summary)
```

## Arguments

- summary:

  A summary returned by
  [`tol_fasta_summary()`](https://PaulESantos.github.io/rtreeoflife/reference/tol_fasta_summary.md).

## Value

A ggplot object.
